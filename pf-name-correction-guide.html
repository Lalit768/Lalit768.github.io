PF Mein Name Correction Kaise Karein?

EPFO ki official FAQ ke mutabik UAN Member Portal mein basic details modify karne ka process available hai. Name aur DOB ko Aadhaar ke according enter karne aur employer approval ki requirement ho sakti hai.

Basic steps

  1. UAN Member Portal mein sign in karein.
  2. Manage ke under Modify Basic Details option check karein.
  3. Aadhaar ke according correct name aur DOB enter karein.
  4. Request submit karke required employer approval ka status check karein.
Agar details match nahi hoti ya request mein issue aaye, official EPFO instructions aur available support channels ko follow karein.

Official source: EPFO UAN & KYC FAQ
